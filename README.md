## Features
- Revamped database architecture by integrating Hibernate ORM, enabling automatic table generation and optimized connection handling, resolving persistent open/close issues.

- Implemented MVC architecture with Thymeleaf for dynamic frontend, Spring Security for role-based access (Admin/Customer), and MySQL for data persistence.

- Enhanced code maintainability through service/DAO layer segregation, bug fixes (image uploads, security), and IDE-agnostic support (IntelliJ/Eclipse).

- Added critical e-commerce features including product/category management, cart logic (WIP), and a responsive UI with Bootstrap.
